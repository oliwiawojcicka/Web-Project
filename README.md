# LSMiniSocial

LSMiniSocial is a web application developed during my Erasmus studies in Spain as part of a university web development course.

The project is a small social media platform created for the La Salle community. It allows users to register, log in, create posts, like and comment on posts, and manage their profiles.

The application was built using CodeIgniter 4, PHP, MySQL, Composer, and Git. It also includes multilingual support and an AI-based feature that helps users improve the content of their posts.

The project was developed collaboratively and focuses on backend logic, API integration, user authentication, database management, and clean web application structure.
